# Welcome to my blog!

This is my very first post. I built this entire blog using **Next.js** and **Markdown** files.

No database needed! Next.js generates all these pages as static HTML files at build time. This makes the website incredibly fast.

## What I learned

- How to use `getStaticProps` and `getStaticPaths`.
- How to style components with Tailwind CSS.
- How to deploy a static Next.js app to GitHub Pages.
